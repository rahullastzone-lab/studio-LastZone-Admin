# **App Name**: LastZone Admin HQ

## Core Features:

- Dashboard Overview: Display key metrics such as total users, total revenue, active tournaments, and pending withdrawal requests.
- Tournament Creation: Enable admins to create new tournaments with details like game type, map, mode, entry fee, prize pool, and schedule.
- Match Management: List upcoming matches and provide a way to update the room ID and password.
- Result Entry & Payout: Allow admins to mark tournaments as completed and automatically distribute winnings to players. Includes using a tool to detect anomalies in results or confirm the payout to a certain player
- User Management: Provide a searchable list of all users with the ability to view user profiles and perform actions like ban/unban and manually adjust wallet balances.
- Withdrawal Processing: Display a table of pending withdrawal requests with options to approve (deduct balance) or reject (refund balance).
- Banner Management: Enable admins to upload images to Supabase Storage for dynamically changing the home page slider banners on the main website.

## Style Guidelines:

- Background color: Dark gray (#09090b) for a dark mode theme.
- Primary color: Gold/Yellow (#FFD700) for accents and highlights.
- Accent color: A slightly lighter shade of yellow (#FFDA63) to maintain consistency while creating contrast.
- Body and headline font: 'Inter', a grotesque-style sans-serif, providing a clean and modern aesthetic suitable for both headlines and body text.
- Sidebar navigation (collapsible on mobile) and a main content area for a responsive design.
- Lucide React icons for a consistent and modern visual language throughout the admin panel.
- Subtle animations and transitions for a smooth user experience when navigating and interacting with the dashboard.
